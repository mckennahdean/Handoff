# Architecture

System architecture diagrams and documentation for Handoff.


## Opening the diagram in draw.io

1. Download `Capstone-Handoff.drawio` from this folder.
2. Go to https://app.diagrams.net
3. When prompted for storage, select **Device**.
4. Click **Open Existing Diagram**.
5. Browse to the downloaded `Capstone-Handoff.drawio` and open it.

To save changes: **File → Save As → Device**, and replace the file in this folder.
