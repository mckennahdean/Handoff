# Handoff

Handoff is an AI-powered knowledge capture and question-answering system
designed to help small businesses document procedures and preserve
operational knowledge.

## Technology Stack

- Frontend: Vue
- Backend: Python/FastAPI
- Database: PostgreSQL + pgvector
- AI: Hosted LLM API
- Embeddings: Vector embedding service
- Transcription: Hosted transcription API
- Development Environment: Docker
